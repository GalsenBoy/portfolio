## Project Overview

Personal portfolio (single page, French) built with React, TypeScript, Vite, SCSS and Framer Motion. No router, no backend: contact is a copy-to-clipboard / `mailto:` button.

## Development Commands

```bash
npm run dev      # dev server with hot reload
npm run build    # tsc + vite build
npm run lint     # eslint, zero warnings allowed
npm run preview  # preview the production build
```

## Architecture

`App` renders the custom `Cursor` and `pages/Home`, which stacks the sections in order:
`Nav` → `Hero` → `Marquee` → `Projects` → `About` → `Terminal` → `Contact` (footer).

### Key Directories

- `src/components/`: one component per section, plus `Logo`, `Cursor` and `SectionHead` (shared section title)
- `src/data/`: static content — `ProjectData.ts` (projects shown in `Projects`, `About` and the terminal) and `Contact.ts` (email / GitHub)
- `src/utils/`: `motion.ts` (shared `EASE` curve, `revealOnScroll()` props) and `format.ts` (`pad2`)
- `src/css/`: one SCSS file per component; global tokens and shared classes (`.section`, `.section-head`, `.eyebrow`) live in `src/index.css`
- `branding/`: logo masters and usage guide

To add a project, add an entry to `src/data/ProjectData.ts` (with its image in `public/`); don't touch component code.

### SEO

Static meta tags and JSON-LD live in `index.html`. Everything that needs an absolute URL (canonical, `og:url`, `og:image`, `sitemap.xml`, the `Sitemap:` line of `robots.txt`) is generated by the `seo` plugin in `vite.config.ts`, only when the `SITE_URL` env var is set at build time. There is no `robots.txt` / `sitemap.xml` in `public/`.

### Styling

- `src/_mixins.scss` is injected into every SCSS file by `vite.config.ts`, so mixins need no import
- Per-project colors are passed to cards as CSS variables (`--surface`, `--accent`)

### Animation

- Framer Motion everywhere; reuse `EASE` and `revealOnScroll()` from `src/utils/motion.ts` instead of inlining easing/viewport config
- Respect `prefers-reduced-motion` (see `Hero` and `Cursor`)

## TypeScript Configuration

- Strict mode enabled with `noUnusedLocals` and `noUnusedParameters`
- Target: ES2020
- Module resolution: bundler mode (Vite-specific)
- JSX: react-jsx (new JSX transform)

## Linting

ESLint is configured for TypeScript + React with:

- `eslint:recommended`
- `plugin:@typescript-eslint/recommended`
- `plugin:react-hooks/recommended`
- `react-refresh/only-export-components` rule for Vite HMR
